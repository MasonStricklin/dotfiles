- Disable hot corners in mission control settings
- Disable inverted scroll in mouse settings
- Disable screenshot thumbnail previews in cmd+shift+5 panel
- Enable Desktop & Dock > “Hold ⌥ key while dragging windows to tile”
- Set “Click wallpaper to reveal desktop” to "Only in Stage Manager" in Desktop & Dock settings
- Increase mouse tracking speed. Typically max - 1 or max - 2 ticks
- Show file extensions via Finder > Preferences > Advanced > “Show all filename extensions
- Install Rectangle, ensure it opens on startup
  - Enable “Green stoplight button maximizes instead of Full Screen”
- Install Spotify, ensure it does not open on startup
- Install Logi Options: https://www.logitech.com/en-us/software/logi-options-plus.html
  - Mission Control button should work as desired out of the box
  - Configure custom gestures for "Desktop Left" and "Desktop Right"
- Install Brave
  - Set default search engine to Google
  - Install Bitwarden/1Password
  - Help > Warn Before Quitting (⌘Q)
    - [Optional] Apply this setting to Chrome, Safari, and any other installed browser
